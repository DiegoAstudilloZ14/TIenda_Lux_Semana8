# Tienda Electrónica PHP

Proyecto desarrollado para la asignatura Programación Web II del Instituto Profesional IACC.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Gestión de productos
- Gestión de clientes
- Carrito de compras
- Checkout completo
- Control de stock
- Consultas SQL con Prepared Statements
- Transacciones MySQL
- Clientes frecuentes
